# Установка на Android &nbsp;·&nbsp; [🇬🇧 EN](ANDROID.md)
Этот гайд поможет вам установить VPN клиент Turnable на Android с использованием Turnable App и Exclave. Предпологается, что у вас есть запущенный сервер Turnable с настроенным маршрутом WireGuard, хотя оно в целом применимо к любому протоколу на основе UDP. Пользователи протоколов на основе TCP могут просто пропустить рекомендации по MTU.

## 1. Установите Turnable App
Turnable App - это официальный клиент Turnable для Android. При первом запуске он скачивает и запускает ядро Turnable, поэтому устанавливать Termux вручную не нужно. Скачайте APK со [страницы релизов](https://github.com/TheAirBlow/TurnableApp/releases).

При первом запуске требуется доступ в интернет для загрузки ядра. Если вы предпочитаете запускать ядро самостоятельно, перейдите к [ручной установке](#3-ручная-установка).

## 2. Настройка клиента
### 2.1. Добавьте клиент
Откройте вкладку **Clients** и добавьте URL подписки от вашего провайдера или вставьте ссылку `turnable://`. В меню добавления есть оба варианта.

### 2.2. Запустите клиент
Запустите нужные клиенты. Приложение показывает адрес прослушивания для каждого из них, к которому будет подключаться ваш VPN или прокси клиент.

## 3. Ручная установка
Если вы предпочитаете запускать ядро самостоятельно, можете использовать Termux. **Не используйте версию из Google Play Store**, так как она сильно устарела. Вместо этого загрузите её со страницы [GitHub Releases](https://github.com/termux/termux-app/releases/latest).

При загрузке выберите правильную архитектуру для вашего устройства:
- **arm64** - Большинство современных смартфонов на Android
- **armeabi-v7a** - Старые устройства Android
- **x86** - Некоторые планшеты и эмуляторы

### 3.1. Быстрая установка
Запустите скрипт быстрой установки, чтобы загрузить и настроить клиент Turnable:

```bash
curl -sSfL https://raw.githubusercontent.com/TheAirBlow/Turnable/refs/heads/main/scripts/quick-client.sh | bash
```

Рекомендуется сначала создать отдельную директорию:

```bash
mkdir Turnable
cd Turnable
# ... теперь запустите команду curl сверху
```

### 3.2. После установки
Скрипт скачивает исполняемый файл `turnable` в текущую директорию. Запустите клиент так:

```bash
./turnable client -l <listen_addr> <config>
```

- `<listen_addr>` - Адрес для прослушивания сокета, например, `127.0.0.1:PORT` для локального доступа или `0.0.0.0:PORT` для доступа из сети.
- `<config>` - URL конфигурации, путь к JSON файлу или путь к текстовому файлу с URL конфигурации.

Чтобы обновиться до последней версии:

```bash
./turnable update
```

### 3.3. Настройка с URL конфигурации
Если у вас есть URL конфигурации, сохраните его в текстовый файл:

```bash
# ... напрямую через echo в файл
echo "your_config_url_here" > wireguard.url
# ... или используйте текстовый редактор
nano wireguard.url
# ... вставьте URL конфигурации, затем нажмите Ctrl+S для сохранения и Ctrl+X для выхода
```

Затем запустите клиент:
```bash
./turnable client -l 127.0.0.1:5080 wireguard.url
```

### 3.4. Настройка с JSON-файлом
Если у вас есть JSON-файл конфигурации, поместите его в ту же директорию и используйте напрямую:

```bash
./turnable client -l 127.0.0.1:5080 config.json
```

## 4. Установка Exclave
Exclave - это клиент прокси для Android, который будет маршрутизировать ваш трафик через клиент Turnable. Установите его из [официального репозитория](https://github.com/dyhkwong/Exclave) или из магазина приложений вашего устройства.

### 4.1. Настройка правил маршрутизации
Удалите все существующие правила маршрутизации и добавьте следующие для блокировки рекламы и защиты от жучков РКН:

| # | Имя                          | Домен/IP                       | Исходящий  | Назначение                                    |
|---|------------------------------|--------------------------------|------------|-----------------------------------------------|
| 1 | Блокировать всю рекламу      | `geosite:category-ads-all`     | Обход      | Предотвращает отслеживание объявлений         |
| 2 | Обход российских доменов     | `geosite:category-ru`          | Обход      | Обход местных ограничений VPN                 |
| 3 | Обход российских IP          | `geoip:ru`                     | Обход      | Обход местных ограничений VPN                 |
| 4 | Блокировать локальный socks5 | Смотрите ниже                  | Блокировка | Предотвращает раскрытие исходящего IP         |
| 5 | Обход по умолчанию           | `0.0.0.0/0, ::/0`              | Обход      | Обход всего остального по умолчанию           |

**Пользовательский JSON для правила #4:**
```json
{
  "inbound": ["mixed-in", "socks-in"],
  "outbound": "block"
}
```

### 4.2. Настройка белого списка приложений
Откройте вкладку **Настройки** в Exclave, включите проксирование для отдельных приложений и выберите только те, трафик которых должен идти через Turnable. Не настраивайте это как правило маршрутизации.

### 4.3. Настройка WireGuard
Если вы вручную создаете конфигурацию WireGuard, убедитесь, что эти поля установлены правильно:

| Поле              | Значение                 | Примечания                                      |
|-------------------|--------------------------|-------------------------------------------------|
| Server            | `127.0.0.1:PORT`         | Используйте PORT, показанный в приложении, или из `-l` при ручной установке |
| MTU               | `1280`                   | Рекомендуется для туннелирования через Turnable |
| Private Key       | [Ваш приватный ключ]     | Из конфигурации вашего клиента                  |
| Server Public Key | [Публичный ключ сервера] | Из конфигурации сервера                         |
| Network Address   | [Ваша сеть]              | Из конфигурации сервера                         |

Если у вас уже есть совместимая с Exclave конфигурация WireGuard, вы можете импортировать её как есть, но вы **должны обновить** поля Server и MTU, как показано выше, иначе она либо полностью обойдет Turnable, либо производительность будет значительно снижена.

## 5. Готово!
Ваше устройство Android теперь настроено на маршрутизацию трафика через VPN клиент Turnable. Exclave будет управлять вашим VPN подключением, используя настроенные надежные правила маршрутизации.
